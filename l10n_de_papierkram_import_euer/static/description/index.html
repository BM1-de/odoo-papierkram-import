Papierkram fixed assets in the EÜR asset register

The bridge between Papierkram Import and Germany EÜR, installed automatically

What it does

  • Takes the fixed assets of the Papierkram import into the asset register of the cash-basis profit statement, with their book value at the takeover date.
  • From then on, the register computes the depreciation and the Anlage AVEÜR.
  • If a row cannot be taken over, nothing is taken over and the log shows the rows to correct.

How it works

  1. Enable the EÜR for the company before the import.
  2. In the Papierkram import, Take Over Fixed Assets (EÜR) is then switched on. Set the Takeover Date (Asset Register) to 31 December of the last year computed with Papierkram.
  3. Check and run the import as usual; Assets opens them in the register.

For an import made before, the button Take Over Fixed Assets (EÜR) on the import takes its assets over later.
