## 20.0.1.0.0 (2026-11-19)

- Migration to Odoo 20, together with `l10n_de_euer` 20.0.
- The list of the assets taken over is handed to the register import as a
  binary value, as Odoo 20 expects.
- The button of the assets uses an icon of Odoo 20 (Material Symbols).

- First version for Odoo 19: the fixed assets of a Papierkram import go into
