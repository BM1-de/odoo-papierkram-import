Papierkram time entries and services in Odoo

An addition to Papierkram Import, installed automatically with Timesheets

What it takes over

  • Goods and services as products with their prices
  • Projects, tasks and time entries; a second import skips the time entries already present
  • The unbilled work: one sales order per customer, so that it can be invoiced in Odoo

How it works

  1. In Papierkram, open Zeiterfassung → Einzelbuchungen, filter Noch nicht abgerechnet and Gesamter Zeitraum and export the CSV.
  2. In the Papierkram import, upload it as Unbilled Time Entries (CSV) and choose which Time Entries to take over: only the unbilled ones, or all of them as history.
  3. Check and run the import; Sales Orders lists the unbilled work.
